# TabiLens

A travel discovery and planning app that turns editorial recommendations into a day-by-day itinerary.

Built by **Team 19** at the **Redpine x NordicNinja x KDDI Tokyo Hackathon on October 23, 2026**.

## Experience

- Discover places through licensed magazine content accessed with Redpine MCP.
- Explore places and nearby Tobu stations on an interactive map.
- Revisit past searches and reload saved results.
- Drag place and article cards into days, reorder them, and insert empty days.
- Open each day's located stops in Google Maps, with route segments where needed.
- Switch between light and dark mode and use map zoom controls.

## Run locally

Use Node.js 24 or later. See [the application README](app/README.md) for backend details.

```sh
cd app
npm ci
```

Create `app/.env`:

```dotenv
REDPINE_API_KEY=your_redpine_key
LLM_BACKEND=api
ANTHROPIC_API_KEY=your_anthropic_console_key
```

Choose the backend by setting `LLM_BACKEND`:

| Backend | Setting | Setup |
| --- | --- | --- |
| Claude API | `LLM_BACKEND=api` | Set `ANTHROPIC_API_KEY` |
| Claude Code | `LLM_BACKEND=claude-cli` | Install `claude` and sign in |
| Antigravity | `LLM_BACKEND=antigravity` | Install `agy` and sign in |

For Antigravity, `AGY_MODEL` selects the model and `AGY_PATH` can specify the CLI executable. Restart the backend after changing the settings.

In separate terminals inside `app/`:

```sh
npm run server
```

```sh
npm run dev
```

Open the URL printed by Vite, normally `http://localhost:5173`. The backend normally listens on port 8787.
